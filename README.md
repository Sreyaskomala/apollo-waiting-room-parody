# 🏥 Apollo 24/7… Waiting | Parody & Consumer Commentary

> *"Healthcare at your doorstep. Allegedly."*

An independent, interactive parody web application roasting the endless delivery loops, broken deadlines, phantom phone calls, and automated excuses of **Apollo 24|7**, **Shiprocket**, and **BlueDart**.

---

## ⚡ What We Built

1. **⏱️ The Master Waiting Chronograph**:
   - Live real-time ticking stopwatch calculating the exact days, hours, minutes, and seconds since the order date (**28 September 2026**).
   - Overdue deadline monitor since the promised delivery date (**29 October 2026**).
   - Real metrics counter: 10+ calls made in 72 hours, 0 phone rings received from the delivery boy, 100% fake "customer unavailable" SMS rate.

2. **🔄 The Infinite Delivery Loop**:
   - Step-by-step interactive simulator showing the daily routine:
     1. Dispatched with BlueDart via Shiprocket
     2. "Out for Delivery" hype SMS
     3. Rider arrives 150m away
     4. "Delivery Failed: Customer Unavailable / Door Locked" (with 0 calls attempted)
     5. Customer calls support; loop restarts tomorrow.
   - Click **"Simulate Today's Delivery Cycle"** to watch the stages animate with sound effects.

3. **🎧 Audio Evidence Vault & Customer Care Player**:
   - Ready for your actual customer care audio recording!
   - **Attach recording:** Drag & drop any `.mp3`, `.wav`, or `.m4a` file directly into the dropzone on the page, or place it in `audio/call-recording.mp3`.
   - **Built-in Simulator Fallback:** If no file is loaded yet, clicking play launches a hilarious synthesized corporate support call with genuine 8-bit elevator hold music + robotic IVR voice generated via Web Audio & SpeechSynthesis.
   - Interactive 10-call log history documenting the calls from Oct 29 to Nov 1.

4. **📡 BlueDart Teleporting Rider Radar**:
   - Live radar simulation tracking rider Mukesh approaching to 150m, screeching brakes, performing a 180° emergency U-turn, and speeding away back to the hub while logging fake "Customer was in another dimension" status updates.

5. **🎲 The Excuse Machine 3.0**:
   - Over 15 painfully accurate, sarcastic excuses reflecting real Indian courier logistics with audio effects and counter tracking.

6. **📋 Consumer Grievance & Social Arsenal**:
   - One-click copy tool for a formal grievance notice citing the **Consumer Protection Act, 2019** (Section 2(47) for unfair trade practices).
   - Pre-formatted Twitter / X thread generator tagging `@Apollo247`, `@BlueDart_`, and `@ShiprocketIndia`.

## 🚀 How to Run & View

### 1. View locally in your browser:
A local web server is already running at:
**[http://localhost:8088](http://localhost:8088)**

You can also simply open `index.html` directly in any browser:
```bash
open index.html
```

### 2. How to attach your audio file later:
- **Option A:** Drop your `.mp3`, `.wav`, or `.m4a` file into the upload box on the web page.
- **Option B:** Save your recording as `audio/call-recording.mp3` in this folder.
